## Release Body

# translatorFork_MOD v10.5.30

## Новое

- В валидации перевода добавлен режим «Ручной» для проверки соотношения длин глав: можно задать минимальный и максимальный коэффициенты длины перевода относительно оригинала. Результаты пересчитываются сразу, без повторного анализа файлов.
- Выбранный режим и ручные коэффициенты сохраняются между открытиями окна. При пересечении границ соседнее значение корректируется автоматически. Нижняя граница включается в допустимый диапазон, верхняя не включается.
- Явно выбранный пресет сохраняется, в том числе при повторном выборе текущего пункта. Если пресет не выбирался вручную, автоопределение языка продолжает работать для каждой книги.

## Исправления

- При невозможности подключения к серверу Gemini теперь показывается понятное сообщение с адресом сервера и рекомендацией проверить интернет-соединение и настройки VPN/прокси. Исходная техническая ошибка сохраняется в деталях для диагностики; порядок повторных попыток сохранён.
- Исправлена опечатка в распознавании сообщения `Cannot connect to host`. Ошибки соединения распознаются по типу исключения; обозначение `ssl:default` само по себе не считается ошибкой SSL/TLS.

Полный список изменений: https://github.com/Rasteo123/translatorFork_MOD/compare/v10.5.29...v10.5.30

## SYSTEM AND INTERFACE TEXT (LitRPG)
This book has a game system. Text that the system or interface displays (notifications, prompts, status panels, skill, item and quest cards, rewards, level-ups) must look the same everywhere:
- Keep it in square brackets. Source 【…】, 〖…〗 and […] around such text become […]. Never turn these brackets into quotation marks and never drop them. Quotation marks inside such text follow the usual rules: 『…』, 「…」 and “…” become «…». This includes a bare skill, item or spell name on its own line and an empty slot: 【】 becomes [ ].
- Keep status and card fields as separate `Key: value` entries, one per line or paragraph exactly as in the source. Never merge fields into a sentence. Keep numbers, ranks and increments as written: `I40 → I50`.
- Keep list markers of skill and item effects: each effect starts with `·`.
Speech, thoughts, spell chants, spell names shouted in battle, news and slogans are not interface text even when the source puts them in 【…】: translate them by the dialogue and quotation rules above.
Chat, messenger and forum messages are not interface text either. Write each message as its own paragraph `Name: «text»` with the sender's name or nickname before the colon, and never put a message in square brackets. A message whose sender the source does not name becomes «text».

System text examples:
Src: <p>【叮！恭喜宿主获得技能：火球术】</p>
Tgt: <p>[Динь! Поздравляем, носитель получил навык: Огненный шар]</p>

Src: <p>【姓名：林凡】</p><p>【等级：3】</p><p>【力量：12→15】</p>
Tgt: <p>[Имя: Линь Фань]</p><p>[Уровень: 3]</p><p>[Сила: 12 → 15]</p>
*(Context: every field stays in its own brackets and paragraph.)*

Src: <p>技能：</p><p>【剑术】</p><p>魔法：【】</p>
Tgt: <p>Навыки:</p><p>[Фехтование]</p><p>Магия: [ ]</p>

Src: <p>【技能：火球术】</p><p>·造成火焰伤害。</p><p>·冷却时间：10秒。</p>
Tgt: <p>[Навык: Огненный шар]</p><p>· Наносит урон огнём.</p><p>· Перезарядка: 10 секунд.</p>

Src: <p>王胖子：【晚上开黑吗？】</p><p>林凡：【来！】</p><p>【人齐了。】</p>
Tgt: <p>Толстяк Ван: «Вечером играем?»</p><p>Линь Фань: «Давай!»</p><p>«Все в сборе».</p>
*(Context: a chat log, not interface text.)*

Src: <p>“【冰柱】！”他大喊。</p>
Tgt: <p>─ «Ледяной столб»! ─ крикнул он.</p>
*(Context: a spell shouted by a character is speech, not interface text.)*

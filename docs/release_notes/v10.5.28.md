# translatorFork_MOD v10.5.28

**Внимание: новая функция «Системные окна» пока работает неточно. Используйте её с осторожностью и проверяйте найденные фрагменты перед применением оформления.**

## Новое

- **Системные окна:** оформление уведомлений LitRPG, карточек статуса, чатов и форумов с предпросмотром и выбором цветов; сохранение оформления при экспорте для Rulate.
- **Системный текст LitRPG:** дополнительные правила перевода, которые можно включить для отдельной книги.
- **Вторая резервная модель** для перевода глав, заблокированных фильтром содержания.
- **Замена уже загруженных переводов глав на Rulate** из файла Rulate MD.

## Исправления

- Улучшены проверки языка и полноты перевода, ускорен анализ текста; исправлено завершение отменённых проверок.
- Исправлено сохранение активных ключей при смене провайдера, обработка сетевых пауз и смена ключа Gemini после длительного ожидания квоты.
- Обновление программы сообщает о ходе установки и её результате после перезапуска.
- Исправлены правила оформления монологов; курсив и жирный текст сохраняются при экспорте для Rulate.
- Обновлена зависимость PyJWT с исправлением обработки некорректных токенов.

Полный список изменений: https://github.com/Rasteo123/translatorFork_MOD/compare/v10.5.27...v10.5.28

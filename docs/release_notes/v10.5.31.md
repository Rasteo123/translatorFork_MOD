# translatorFork_MOD v10.5.31

## Arbz / Qroute

- Обновлён провайдер «Arbz / Qroute (OpenAI API)»: 27 доступных моделей Gemini, GPT, Grok и Claude 4.6 из текущего каталога сервиса. Сохранены полные идентификаторы моделей Plus.
- Добавлен отдельный провайдер «Arbz / Qroute — Claude» для Claude Opus 5 и 4.8 через нативный Anthropic Messages API. Используется тот же ключ Qroute; его нужно добавить в выбранный пункт провайдера.
- Исправлен идентификатор Gemini 3.5 Flash High. Убраны устаревшие модели и временно недоступные Gemini 3.1 Pro.
- Поддерживаются обычные ответы и потоковая передача. Запрос к сервису с настоящим API-ключом в рамках выпуска не проверялся.

## Обновления безопасности

- Обновлены закреплённые multidict до 6.9.1 и Werkzeug до 3.1.9: исправлены CVE-2026-104874 (утечка ссылок в операциях над представлением items) и CVE-2026-102598 (обработка специальных имён устройств Windows в safe_join).

## Исправления из main после v10.5.30

- Перевод с локально повторяющимися фразами теперь распознаётся как зацикливание и не принимается как готовый результат.

Полный список изменений: https://github.com/Rasteo123/translatorFork_MOD/compare/v10.5.30...v10.5.31

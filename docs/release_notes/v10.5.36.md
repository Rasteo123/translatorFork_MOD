# translatorFork_MOD v10.5.36

- В Arbz / Qroute добавлены Gemini 4 Neon XHigh, High, Medium и Low.
- В списке Arbz / Qroute появились две отдельные позиции GPT‑6.2 Sol с пометками Codex и Plus. Codex использует Responses API, что устраняет ошибку 502 при отправке через Chat Completions.
- Arbz / Qroute прекращает автоматические повторы, если модель исчерпала лимит токенов и вернула пустой глоссарий.
- При разбиении EPUB сохраняется один XML-пролог на главу.
- В выпуск вошло исправление Gemini 3.8 Flash из v10.5.35. Google Gemini Free отправляет свой идентификатор модели, а в Arbz / Qroute модель имеет отдельное название.

# Порог короткого перевода для CJK-оригиналов

## Цель

Считать перевод с иероглифического оригинала подозрительно коротким, если отношение
длины перевода к длине оригинала меньше `2.80`.

## Область изменения

Существующая категория CJK сохраняется без изменения и включает китайские,
японские и корейские оригиналы. Минимальный коэффициент меняется с `1.80` на
`2.80` в двух связанных сценариях:

1. Ручной валидатор ошибок показывает причину «Длина T/O».
2. Автоматический валидатор отправляет короткую главу на повторный перевод.

Для алфавитных оригиналов текущие пороги не меняются.

## Граничное поведение

- Коэффициент меньше `2.80` считается ошибкой короткого перевода.
- Коэффициент, равный `2.80`, не считается слишком коротким.
- Пользовательский порог автоматического режима выше `2.80` продолжает иметь
  приоритет, как и сейчас.

## Реализация

- Изменить нижнюю границу CJK-пресета ручного валидатора на `2.80`.
- Изменить общий CJK-минимум автоматического режима на `2.80`.
- Обновить пояснение пресета, чтобы интерфейс показывал актуальный порог.

## Проверка

- Регрессионный тест подтверждает CJK-минимум `2.80` в автоматическом режиме.
- Тест ручного валидатора подтверждает ошибку ниже `2.80` и отсутствие ошибки на
  границе `2.80`.
- Тест подтверждает, что алфавитный порог не изменился.

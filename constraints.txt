# Локфайл: точные версии всего дерева зависимостей.
#
# Зачем. requirements.txt перечисляет пакеты без версий, поэтому сборка брала
# то, что оказалось свежим в день выпуска. Так в релиз уехал numpy 2.4, который
# требует x86-64-v2 и роняет старт на старых процессорах (см. отчёт о
# «Importing the numpy C-extensions failed» в 10.5.25). Здесь numpy закреплён
# на последней 2.3.x; на остальные 110 пакетов это ограничение не повлияло.
#
# Как применять:
#     pip install -r requirements.txt -c constraints.txt
# Файл ничего не устанавливает сам — только задаёт версии тому, что ставится.
# Поэтому он безопасно накрывает и requirements-dev.txt.
#
# Как пересобрать (после правки requirements.txt):
#     python -m pip install --dry-run --ignore-installed \
#         -r requirements.txt -r requirements-dev.txt \
#         -c <(echo 'numpy<2.4') --report resolve.json
# и переписать версии отсюда. Резолюция снята на macOS/Python 3.11; все
# платформенные колёса проверены на наличие сборки под win_amd64 cp311.
# Пакеты, у которых колёс нет вообще (jieba, PyAudio, docopt), собираются из
# исходников — именно поэтому в конвейере нельзя включать --only-binary :all:.
#
# Снято: 2026-09-20. Python 3.11, 111 пакетов
# (50 прямых, 61 транзитивных).
